# Frontend Design State

- Brief: multi-branch Indonesian laundry operations platform with owner CMS and mobile customer/staff application.
- Direction: clean garment-care command center using royal-blue trust cues, pale-blue operational surfaces, and receipt-inspired order tickets.
- Primary personas: customer, branch admin, owner, superadmin.
- Taste constraints: bright and dimensional without decorative clutter; operational information outranks marketing flourish.
- Accessibility constraints: WCAG 2.2 AA, 44 px targets, keyboard support, reduced motion, color-independent status, stable slow-network states.
- Signature component: `OrderTicket` with dashed receipt separator and status-first hierarchy.
- Current phase: Phase 1 core operations.
- Accepted debt: final branding, charts, Android hardware certification, and translated locales are deferred as documented in `DESIGN.md`.
