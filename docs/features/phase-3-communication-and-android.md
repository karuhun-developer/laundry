# Phase 3: Communication and Android

Status: Planned

## Outcome

Staff can open a prefilled WhatsApp conversation from a validated template, and the mobile application can be installed and tested as an Android package.

## Scope

- Organization-level and branch-level message templates.
- Supported variables with preview and validation.
- URL-safe `wa.me` generation.
- Status-change message suggestions without silent background sending.
- Capacitor Android shell, permissions, icons, splash screen, signed-build guide, and device QA.

## Constraints

- This phase does not automate WhatsApp delivery or use unofficial WhatsApp APIs.
- No offline synchronization is introduced.
